# ADR 0005. Драйверы Windows

Статус: принято  
Дата: 2026-10-27

## Контекст

На Windows 10 нет пользовательского API, который регистрирует микрофон для всех приложений. `MFCreateVirtualCamera` появляется только в Windows 11 сборки 22000. Виртуальный монитор делается через IddCx. Выбран путь собственных драйверов с EV-сертификатом и attestation.

## Решение

Три компонента, каталог `host-win/driver`, лицензия не MIT:

1. IddCx ветки 1.4 с проверками `IDD_IS_FUNCTION_AVAILABLE`. Пол продукта — Windows 10 1809.
2. AVStream-камера. Один драйвер покрывает Windows 10 1809 и Windows 11, поэтому отдельный путь через `MFCreateVirtualCamera` не делаем.
3. Аудиодрайвер WASAPI-endpoint для виртуального микрофона.

Пользовательский процесс и драйвер встречаются в именованной общей памяти. Раскладка версии 1 описана в протоколе и проверяется кодеком `span-protocol`: `SPANCAM1` и `SPANMIC1`, little-endian. Кадр публикуется до смены активного слота или счётчика записи.

Разработка идёт с test signing. Установщик для обычного пользователя подписывается attestation. Пока подписи нет, демо v1 показывает видео окном и пишет в ту же общую память, чтобы драйвер подключился без смены протокола.

## Последствия

Сложность — XL, риск высокий: HLK, отзыв подписи, разница версий IddCx. Риск снижается тем, что контракт памяти уже зафиксирован и не зависит от WDK.
