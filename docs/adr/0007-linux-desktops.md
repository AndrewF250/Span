# ADR 0007. Рабочие столы Linux

Статус: принято  
Дата: 2026-10-27

## Контекст

Приёмка обязана проходить и в GNOME on Xorg, и в KDE Plasma X11. Оба сеанса должны видеть дополнительный выход через `xrandr` и обычную камеру V4L2.

vkms на ядрах Ubuntu 22.04 не является рабочим путём низколатентного расширения текущей сессии. Модуль создавался для тестов композитора. Забрать из него кадр рабочего стола с нужной задержкой нельзя обещать.

## Решение

- Эталоны: GNOME on Xorg и KDE Plasma X11 на Ubuntu 22.04. Debian 12 — та же схема, best-effort, пока эталон гоняется на Ubuntu.
- Extend: модуль `evdi` отдельным процессом. Он GPL, в MIT-крейты не линкуется.
- Камера: `v4l2loopback`, тоже вне дерева ядра и тоже не линкуется в `host-core`.
- Микрофон: PulseAudio на Ubuntu 22.04 и PipeWire там, где сеанс уже на нём. Интерфейс один: источник, который видят обычные приложения.
- Ввод: `uinput` и правило udev. Захват комбинации для настройки хоткея — XRecord, без `EVIOCGRAB`.
- Wayland остаётся best-effort и в приёмку v1 не входит.

`evdi` и `v4l2loopback` не подписаны ключом дистрибутива. При включённом Secure Boot установщик объясняет запись MOK и отказывается поднимать Extend или виртуальную камеру, пока модуль не загружен. `span-doctor` показывает это явно.

## Последствия

Сложность — L, риск средний. Два рабочих стола удваивают ручную приёмку. Secure Boot — шаг установки, а не тихий отказ.
