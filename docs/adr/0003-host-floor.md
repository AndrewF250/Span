# ADR 0003. Пол операционных систем хоста

Статус: принято  
Дата: 2026-10-27

## Контекст

Исходный пол Windows 10 1607 и Ubuntu 20.04 / Debian 11 не совпадает с выбранной оболочкой.

- WebView2, без которого нет Tauri на Windows, поддерживается начиная с Windows 10 SAC 1709.
- Драйвер IddCx 1.4 не загружается на 1607–1709. Один современный драйвер живёт с Windows 10 1803, если проверять функции во время выполнения. На 1607–1709 потребовался бы второй драйвер ветки 1.0.
- Tauri 2 требует `webkit2gtk-4.1`. Этот пакет есть в Ubuntu 22.04 и Debian 12 и отсутствует в Ubuntu 20.04 и Debian 11.

## Решение

Оболочка хоста — Tauri 2.

- Windows: 10 1809 x64. ARM64 — позже, не в приёмке v1.
- Linux: Ubuntu 22.04 и Debian 12.
- `host-core` не линкует WebView. Протокольный крейт собирается отдельно от оболочки.

Ядро по-прежнему не зависит от экрана Tauri, но продукт эти старые ОС не поддерживает: отдельной урезанной оболочки для 1607 и 20.04 нет.

## Последствия

Сложность — M, риск низкий. Пользователи Windows 10 1607–1803 и Ubuntu 20.04 остаются вне продукта. Это записано в матрице совместимости.
